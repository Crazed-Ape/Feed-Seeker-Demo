# Friday Playtest Kit

Three tables of four at {{pick.cafe}}, one prototype copy per table.

## Packing List

In packing order: the first item goes in at the bottom of the bag, and the last item in is the first one you need at the table.

1. **Spare bag for tokens.** Needed last, when packing up. Check: it's empty and it closes.
2. **Feedback sheets.** Twelve, one per player. Check: you've counted twelve.
3. **Pens.** Twelve, one per player. Check: every pen writes.
4. **Sticky notes.** One pad, for seat numbers, quick notes and anything that needs flagging on a box. Check: the pad has at least twelve sheets left.
5. **Season timing sheets.** Three, one per table. Check: each has the table number written at the top.
6. **Three prototype copies, tokens counted.** Needed first, for teaching. Check: each copy's tokens are counted, all three copies hold the same number, and the total is written on a sticky note inside each lid.

## Season Timing Sheet

One per table. Start the timer on the first spring turn and write the time at each change of season.

## Session Plan

Plan 75 minutes for each session.

| Step | Minutes | What happens |
|---|---|---|
| 1. Teach | 10 | Teach the game the same way at all three tables. |
| 2. Play | about 45 | One full game, timed season by season. |
| 3. Sheets and chat | 15 | Everyone fills in a sheet, then a short chat. |
| 4. Slack | 5 | Someone always arrives late. |
| Total | 75 | |

## Notes

1. Keep the timer face down, so nobody plays faster for the clock.
2. Set the three tables a little apart, so one table's rules talk doesn't drift to the next.
3. Count tokens again when packing up, before anything goes in the spare bag.
